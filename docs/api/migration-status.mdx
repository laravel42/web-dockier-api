# Migration Status Endpoints

> **Removed.** The Encore → Fastify migration is complete, so the per-service
> `GET /<service>/_migration/status` observability endpoint has been retired
> along with its scaffolding (`services/migration-placeholders.ts`).

All services below are fully migrated to Fastify route modules under
`backend/src/services`:

- `auth`
- `users`
- `projects`
- `roles`
- `deploy`
- `notifications`
- `integrations`
- `code-analysis`
- `git-integration`
- `image-builder`
