# Dockier Fastify API Docs

This Mintlify site documents the migration from Encore to Fastify microservices with Supabase storage and OpenAPI-first contracts.

## Live documentation endpoints

- Swagger UI (runtime): `http://localhost:4000/docs`
- OpenAPI JSON (runtime): `http://localhost:4000/docs/json`

## Scope in this pass

- Fully migrated Fastify services:
  - `auth`
  - `users`
  - `projects`
  - `roles`
  - `deploy`
  - `notifications`
  - `integrations`
  - `code-analysis`
  - `git-integration`
  - `image-builder`
