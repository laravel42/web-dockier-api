# Migration Plan

## Architecture

- Each domain remains a dedicated microservice.
- Service runtime: Fastify + TypeScript strict mode.
- Storage: Supabase Postgres (`@supabase/supabase-js` admin client).
- API contract: route-level Zod schemas -> OpenAPI via `fastify-type-provider-zod`.

## Endpoint conversion strategy

1. Preserve existing route paths and payload semantics.
2. Convert shared concerns first (auth, validation, error normalization).
3. Migrate high-traffic CRUD services before asynchronous integrations.
